# Обратная связь — версия 0.5

Можно использовать псевдоним. Не указывай контакты и имена собеседниц. Заполняй копию после использования; отправляй организатору вручную, если хочешь поделиться.

- Версия: 0.5.
- Помощник / модель, если известна:
- Ситуация: анкета / продолжение / пауза / другое.
- Цель:
- Был ли хотя бы один подходящий вариант: да / с правками / нет.
- Что сделал: отправил без изменений / отредактировал / написал сам / решил не отвечать.
- Номер выбранного варианта:
- Что пришлось изменить и почему:
- Было ли легко продолжить разговор своим голосом: да / частично / нет / ещё не пробовал.
- Что звучало неестественно, грубо, скучно или слишком смело:
- Что мешало пользоваться инструментом:
- Хотелось бы воспользоваться снова: да / возможно / нет.
- Необязательное краткое описание реакции: поддержала игру / ответила буквально / сменила тему / выразила дискомфорт / ответа пока нет / другое.

Скриншот не нужен. Если добавляешь обезличенный пример, отдельно укажи, разрешаешь ли использовать его для внутренней доработки. Разрешение на публичное размещение этим не даётся.
